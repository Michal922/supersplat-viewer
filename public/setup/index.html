Konfiguracja HTTPS dla iPhone

  1. Pobierz CA: 📥 rootCA.cer
  2. Zainstaluj profil na iPhonie (Ustawienia → profil) i włącz pełne zaufanie w: Ustawienia → Ogólne → Informacje → Ustawienia zaufania certyfikatów.
  3. Uruchom viewer: https://<IP>:3443/

Android/desktop

Po staremu: http://<IP>:3000/ lub http://localhost:3000/

Ten serwer działa lokalnie. Jeśli zmienisz IP hosta, wygeneruj cert ponownie:
npm run gen-cert -- <NOWE_IP>
